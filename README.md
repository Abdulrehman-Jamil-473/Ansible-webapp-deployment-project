Ansible Practice — Web App Deployment Project

A mini project deploying a web app across webservers and dbservers groups using Ansible.

Covers
Ad-hoc commands & idempotency
Playbooks & roles (webserver, dbserver, appusers)
Jinja2 templates with variables
Handlers (reload/start services)
Loops (creating multiple users)
Conditionals (when — OS/host-group based)
Error handling (ignore_errors)
Ansible Vault (secure DB password)
